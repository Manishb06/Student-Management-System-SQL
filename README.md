# Student Management System (SQL)

## Overview

A SQL-based Student Management System developed using MySQL to demonstrate database design, data manipulation, and query optimization.

## Features

- Database creation
- Students, Courses, Faculty, Enrollments tables
- Primary & Foreign Keys
- INSERT, UPDATE, DELETE
- INNER JOIN
- GROUP BY
- HAVING
- ORDER BY
- Aggregate Functions
- VIEW
- Stored Procedure
- INDEX

## Technologies

- MySQL Server 8.0
- MySQL Workbench

## Skills Demonstrated

- Database Design
- SQL Queries
- Relational Database Management
- Data Analysis
- Stored Procedures
- Views
- Indexing
